# 课序使用帮助

课序用于本机课程作业演示，账号、报告、代码、成绩和检测结果都保存于安装时选择的数据目录。

## 安装和启动

双击 Setup.exe，选择程序目录和独立数据目录。安装完成后打开课序，浏览器访问本机工作台。服务控制窗口中的“打开工作台”可再次打开浏览器；关闭控制窗口才会退出服务，关掉浏览器标签不会退出服务。

第一次启动提供虚构演示账号 admin、teacher、teacher2、student01–student04，密码 DemoPass123!。管理员可在用户管理中改资料、重置密码或停用账号。第二次启动保留已有数据。

## 学生操作

登录后在工作台切换全部、待完成、已提交、已反馈。进入作业先查看课程、要求、截止时间和必交类别，再添加报告与代码。报告支持 DOCX/PDF/TXT，代码支持 PY/JAVA。单文件 20 MiB、一次 50 MiB、最多 20 个附件。

提交完成后刷新页面确认版本。重交会建立新版本，历史原件继续保留，旧版成绩不会自动复制到新版。网络响应丢失时，在原对话框中直接重试；更改附件或备注会产生新的提交请求。教师发布成绩后，在当前提交中查看成绩与评语。

## 教师操作

在作业管理中新增草稿或保存并开放提交；已有作业编辑时可保存修改并保持当前状态。关闭提交后学生可查看历史，但不能新交。已有学生提交后不能改回草稿，也不能改变满分。

进入批改页面选择学生及附件，查看提取内容或下载原件，填写成绩与评语并保存。进入成绩页面核对已交、未交、已批改、平均分及分布，再点击发布成绩。修改已经发布的成绩需要重新发布。CSV 导出包含选课学生的最新状态。

相似检测页面可添加统一报告模板或代码骨架，然后开始检测。报告与同语言代码分别比较，只取每位学生最新版本。双方覆盖率可能不同，80% 只用于筛选。进入片段页面核对原件、位置与上下文，记录待复核、已排除或需进一步核实；复核不会自动扣分。

## 管理员操作

管理员维护账号角色和可用状态、课程教师归属及学生选课。最后一个可用管理员不能停用。已有提交的选课关系受保护；课程归档后保留历史并停止作业写入。教师只能操作自己的课程，学生只能查看自己的提交和已发布成绩。

## 常见问题

登录提示无法连接本机服务：先打开“课序”本机服务窗口，再刷新浏览器。默认安装版地址是 http://127.0.0.1:8765；如果手动指定其他端口，要打开对应地址。关闭浏览器标签不会退出服务，关闭控制窗口才会停止服务。账号或密码错误会显示单独的认证提示，连接错误不表示密码错误。

端口被其他软件占用：换用启动参数 --port，例如 8768。程序不会终止其他软件。启动失败时检查数据目录内的 startup.log。

PDF 显示无法提取：纯扫描 PDF 没有文字层，本版不做 OCR；原件可下载，但不能把不可检测当作 0% 相似。损坏文档也应查看原件或重新提交可解析文件。

检测显示历史快照：学生重交或公共模板修订后结果会过期，重新检测即可。服务重启时未完成任务显示已中断，不会假称检测完成。

备份与迁移：先关闭服务，完整复制数据目录；数据库、uploads、secret.key 一并保存。重新安装选择原数据目录。卸载程序不会删除独立数据目录，删除数据前应自行确认备份。

本版是 Windows 桌面单机演示系统，不提供手机适配、在线考试监考或自动判定作弊。安装后的功能视频与本帮助文档配套使用。
