# 默认头像与课程图片

七张人物头像和三张书本图片由内置 imagegen 根据文字描述生成，作为演示系统的虚构默认素材。人物不代表组员、教师或真实用户，书本不代表真实出版物。图片保存在 `frontend/public/images/`，随前端和 Windows 安装包一起分发，页面不访问外部图片服务。

人物头像采用自然光、居中头肩构图、浅灰背景与低饱和衣着，保留自然皮肤质感。管理员为成年男性，陈老师为戴圆框眼镜的男性教师，林老师为短发女性教师；四个虚构学生分别使用深蓝上衣男生、米色上衣女生、眼镜男生和浅紫上衣女生照片。演示账号按账号名固定对应；其他账号使用按账号名稳定选择的同角色默认照片。

课程图片采用真实纸张和布面精装书质感的摄影风格，柔和侧光，书本位于画面右侧，左侧留白。Java 为浅紫色、Python 为灰绿色、软件设计为雾蓝色。书封文字分别为 JAVA、PYTHON、SOFTWARE DESIGN。作业列表使用相同课程书图的缩略图；课程卡片通过 CSS 遮罩和背景渐变，使书图逐渐融入文字区域。

本轮为现有界面的局部视觉修改，按用户给出的照片与渐变要求直接实施。使用 `frontend/scripts/check-photo-ui.mjs` 抓取真实 Chromium 页面，等待加载和两秒渲染，再保存全页及三个滚动位置截图；检查 1440 和 1280 像素桌面宽度下图片加载、外部请求、脚本错误和横向溢出，并人工查看截图确认文字和图像效果。
